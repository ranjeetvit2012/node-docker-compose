# 🚀 Node.js Backend with TypeScript, Docker, and PostgreSQL

A modern Node.js backend project built with **TypeScript**, containerized using **Docker**, and orchestrated with **Docker Compose**. This setup includes a **PostgreSQL** database and uses **Prisma ORM** for database management. Designed for **scalability**, **development speed**, and **production readiness**, it provides full **TypeScript type safety**, **script automation**, and a clean project structure.

---

## 📦 Features

- TypeScript for type-safe development
- Prisma ORM with PostgreSQL
- Docker & Docker Compose for containerization
- Clean and scalable project architecture
- Ready for local development and production use
